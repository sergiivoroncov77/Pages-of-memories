# Истории близких

Мобильный PWA-прототип для сбора голосовых воспоминаний семьи. Приложение предлагает вопросы, имитирует запись ответа, сохраняет демонстрационную расшифровку, фото и теги, а затем собирает воспоминания в таймлайн и семейную книгу.

Это рабочий интерфейсный каркас на React + TypeScript + Vite. Backend, авторизация, реальный микрофон, хранение аудио и синхронизация намеренно оставлены на следующий этап.

## Требования

- Node.js 20+
- pnpm 11.25.0

В проекте используется только pnpm.

## Запуск

```powershell
cd D:\Projects\family-stories
pnpm install
pnpm dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Сборка и проверка:

```powershell
pnpm build
pnpm lint
```

## Что можно проверить

- Главная показывает активный проект, следующий вопрос, близких и последние воспоминания.
- «Близкие» открывает профиль человека, прогресс, вопросы и ответы.
- Сессия вопроса проходит путь «вопрос → запись/пауза → черновик расшифровки → воспоминание».
- Карточка воспоминания содержит mock-аудиоплеер, расшифровку, фото, дату, теги и источник.
- «Книга» поддерживает поиск, фильтры по рассказчику и тегам, карточки и таймлайн.
- «Приглашение» объясняет сценарий без обязательной установки приложения и показывает mock-ссылку.
- «Экспорт» позволяет выбрать истории, настроить издание и скачать демонстрационную HTML-книгу.
- «Настройки» содержат локальные переключатели приватности, экспорт JSON и сброс демо.

## Архитектура

```text
src/
  app/          маршрутизация, оболочка и глобальное состояние
  components/   переиспользуемые UI-компоненты
  data/         типы, seed-данные и localStorage-репозиторий
  features/     экраны по продуктовым сценариям
  lib/          форматирование, id и работа с браузерным хранилищем
  styles/       дизайн-токены и адаптивные стили
```

`AppStateProvider` предоставляет экранам единый snapshot и операции над ним. Замена `src/data/repository.ts` на API-клиент позволит подключить реальный backend без переписывания страниц.

## Данные

Все данные демонстрационные. Первый запуск берёт `src/data/seed.ts`, затем snapshot сохраняется в `localStorage` под ключом `family-stories:snapshot:v1`.

Аудио не записывается: таймер и плеер имитируются. Фотографии — локальные SVG-иллюстрации без персональных данных.

## PWA

Подключён `vite-plugin-pwa`: генерируются manifest и service worker. Приложение можно установить из поддерживаемого браузера. При первом запуске проверьте production-сборку через:

```powershell
pnpm build
pnpm preview
```

## Известные ограничения

- нет backend, аккаунтов и синхронизации;
- нет доступа к микрофону и реальных аудиофайлов;
- расшифровка создаётся демонстрационным текстом;
- скачиваемая книга — HTML-макет, не PDF и не печатный заказ;
- приглашение и ссылка существуют только внутри прототипа;
- данные привязаны к браузеру и могут быть очищены пользователем.
