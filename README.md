# Истории близких

Локальный PWA-прототип книги воспоминаний. Книга разбивается на главы и моменты: у каждого момента есть основной рассказ, отдельные взгляды участников, фотографии, видео, голосовые материалы и отклики. Старый сценарий «вопрос → голосовой ответ» оставлен как мягкий способ наполнить книгу.

Это рабочий local-first интерфейсный прототип на React + TypeScript + Vite. Метаданные книги сохраняются в snapshot `localStorage`, а голосовые записи, фото и видео — в IndexedDB этого устройства. Общие книги синхронизируются через семейное хранилище на Google Диске владельца — маленький скрипт Google Apps Script в его аккаунте ([инструкция](docs/GOOGLE_DRIVE_SETUP.md)). Расшифровка речи оставлена на следующий этап.

## Требования

- Node.js 20+
- pnpm 11.25.0

В проекте используется только pnpm.

## Запуск

```powershell
cd D:\Projects\family-stories
pnpm install
pnpm dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Сборка и проверка:

```powershell
pnpm build
pnpm lint
pnpm test
```

Локальная замена семейного хранилища (настоящий `Code.gs` на поддельных сервисах Google) — `pnpm cloud:mock`; адрес `http://127.0.0.1:8787/macros/s/mock/exec` вставляется в «Настройки → Семейное хранилище».

## Что можно проверить

- Главная показывает книгу, главы, последние моменты и мягкий вход через следующий вопрос.
- «Близкие» открывает профиль человека, прогресс, вопросы и ответы.
- Сессия вопроса проходит путь «вопрос → запись/пауза → черновик расшифровки → воспоминание».
- Карточка воспоминания содержит mock-аудиоплеер, расшифровку, фото, дату, теги и источник.
- «Книга» начинается с полки «Мои книги»: можно создать сколько угодно книг (у каждой свои главы, обложка и фильм), переключаться между ними, переименовать или удалить книгу. Главы добавляются, переименовываются, переставляются стрелками и удаляются; в пустую главу можно сразу добавить момент. Поиск ищет по заголовкам, людям и текстам; момент можно отметить избранным, изменить или удалить.
- «Семейное хранилище» (`Настройки`) подключает приложение к скрипту на Google Диске владельца. Книга выгружается кнопкой «Выгрузить в облако» (новые книги — сами), создатель книги приглашает близких в «Поделиться» ссылкой. Близкий открывает ссылку и нажимает «Принять приглашение» — без регистрации. Рассказы, фото, голос, видео, отклики, правки и удаления приходят всем участникам: сами раз в пару минут и после правки, и по кнопке «Синхронизировать». Создатель видит участников, меняет их имена в книге и может исключить человека. Участник удаляет только то, что добавил сам; создатель — что угодно. Создатель может убрать книгу только со своего устройства (и вернуть позже) или удалить у всех; близкий, удаляя книгу у себя, выходит из неё и получит её снова только по новому приглашению. «Очистить и начать» у близких ничего не удаляет. Инструкция по установке скрипта — `/cloud/setup`.
- «Поделиться» также отправляет книгу одним HTML-файлом через меню «Поделиться» устройства (MAX, почта, Bluetooth; WhatsApp и Telegram в России заблокированы) или скачивает его. Близкий открывает приложение, нажимает «Книга → Открыть файл книги» — книга появляется у него на полке со всеми фото, голосами и подписями. Он дописывает своё и присылает файл обратно: новые главы, моменты, рассказы и отклики добавляются, правки сохраняются по более свежей версии, повторы не дублируются. Открытый отдельно файл сам объясняет, что делать, и ведёт в приложение.
- «Близкие» позволяют добавить, изменить и удалить человека; новому участнику сразу даётся восемь вопросов для первого разговора. Страница «Пригласить» собирает текст приглашения и файл книги.
- Открытый момент разделяет «Рассказ», «Взгляды», «Материалы» и отдельные «Отклики».
- В момент можно добавить текст, рассказ голосом (кнопка «Рассказать голосом» сразу включает микрофон: пауза, прослушивание, перезапись) или фото-, видео- или аудиофайл. Рассказ голосом появляется в книге на странице «Голос из прошлого» и в фильме главы.
- Рассказы и отклики подписываются только своим именем в этой книге или анонимно; от имени других участников писать нельзя. Свой рассказ или отклик можно изменить после добавления (слова и подпись); в общей книге — только тому, кто его добавил, и это проверяет и семейное хранилище. Рассказ из интервью меняется в ответе на вопрос.
- Моменты главы идут по дате события, от ранних к поздним; моменты без даты — после них, в порядке добавления. В каждой главе есть своя кнопка «Добавить момент», а «Изменить главу» — рядом с её названием.
- «Экспорт» собирает выбранные моменты по главам и скачивает переносимую HTML-книгу с текстом, откликами и медиа с устройства, встроенными в файл как base64.
- «Читать книгу» (`/read`) открывает книгу как настоящую: обложка, оглавление, главы с буквицами, фотографии и отклики на страницах. Страницы переворачиваются в 3D — разворотом на компьютере и по одной на телефоне; листать можно свайпом, стрелками, клавишами и ползунком. Текст разбивается на страницы по реальному размеру экрана.
- «Фильм главы» (`/chapters/:id/film`) собирает всё, что добавили в главу, в один ролик: титры главы и моментов, фотографии с медленным наездом камеры, страницы рассказов, голосовые записи поверх фото, видео и финальные титры с именами рассказчиков. Переходы между моментами — перелистывание страницы.
  - Переключатели: комментарии близких (отклики), рассказы текстом, голосовые записи, озвучка моментов, видео, тихая музыка; формат 16:9 или 9:16 для телефона.
  - «Озвучка»: для каждого момента можно записать свой голос за кадром, подглядывая в текст рассказа. Музыка автоматически стихает, когда кто-то говорит.
  - «Собрать видео» записывает фильм в реальном времени в MP4 (H.264, где браузер умеет) или WebM; файл можно скачать или отправить через «Поделиться».
- При первом запуске (и при первом открытии приглашения) приложение спрашивает имя — это профиль, без пароля (`/profile`). Имя профиля — для самого человека, участники книг его не видят. В каждую книгу человек сам вводит имя, под которым его там видят, — любое: при создании книги, при принятии приглашения, при выгрузке старой книги в облако; ничего не подставляется. Имена меняются в профиле; создатель книги может переименовать любого участника, остальные — только себя и тех, кого добавили сами.
- В свой профиль можно войти с любого устройства — телефона, планшета, компьютера: «Настройки → Устройства → Подключить другое устройство» показывает одноразовый QR-код и ссылку на 15 минут, второе устройство открывает её и нажимает «Войти в профиль» (`/device`). Все устройства равноправны: те же общие книги, имена и права; в «Устройствах» любое можно переименовать или отключить. Книги «только на этом устройстве» на другие не переходят.
- Книги, пришедшие из облака, не скачивают фото, голос и видео сразу: фото открываются из облака уменьшенной копией и остаются во временном кэше, голос и видео играют потоком. У каждой книги свои кнопки — на странице книги и в «Настройки → Книги и файлы на этом устройстве»: «Выгрузить в облако», «Скачать на устройство» (чтобы смотреть без интернета) и «Удалить файлы с устройства» (освободить место).
- «Настройки» содержат тему, экспорт и восстановление JSON, переключатель «Показывать демо-книгу» (по умолчанию выключен: добавляет демо-семью и её книгу рядом с вашими и убирает их обратно) и «Начать с чистого листа».

### Проверка сохранения и восстановления

1. Откройте любой вопрос, завершите демонстрационную запись, выберите несколько тегов и фотографию, затем нажмите «Оставить черновиком».
2. Перейдите на другой экран и перезагрузите страницу. Снова откройте тот же вопрос: выбранные теги, фотография и её подпись должны сохраниться вместе с текстом и длительностью.
3. Нажмите «Добавить в книгу» и проверьте, что воспоминание содержит те же теги и фотографию. Для проверки очистки фото выберите «Без фото» перед сохранением.
4. В DevTools замените `family-stories:snapshot:v1` на JSON с `version: 1`, но с неверными типами в `people`, `questions`, `memories`, `drafts` или `settings`, затем перезагрузите приложение. Оно должно загрузиться на безопасных нормализованных данных или с пустым архивом без ошибки рендера.

## Архитектура

```text
src/
  app/          маршрутизация, оболочка и глобальное состояние
  components/   переиспользуемые UI-компоненты
  data/         типы книги, seed-данные, миграция и localStorage-репозиторий
  features/     экраны по продуктовым сценариям (reader — читалка, film — студия фильма)
  lib/          форматирование, id, браузерное хранилище; lib/film — план, отрисовка, музыка и запись фильма
  sync/         семейное хранилище: записи книги, сетевой клиент, синхронизация, React-провайдер
server/
  google-apps-script/  сервер хранилища (Code.gs, appsscript.json) и dev/ — поддельный Google для тестов
  styles/       дизайн-токены и адаптивные стили
```

`AppStateProvider` предоставляет экранам единый snapshot и операции над ним. Замена `src/data/repository.ts` на API-клиент позволит подключить реальный backend без переписывания страниц.

## Данные

Первый запуск открывает пустой архив; демо-семья и её книга из `src/data/seed.ts` добавляются переключателем в настройках (`src/data/demoBook.ts`, флаг `settings.demoBook`). Архив, открытый в прежней версии, при запуске теряет демо, если в него не добавляли своё и демо-книга не общая. Snapshot сохраняется в `localStorage` под ключом `family-stories:snapshot:v1`.

Главный пользовательский путь теперь такой: `Книга → Глава → Момент → Взгляды / Материалы / Отклики`. Старые массивы `memories`, `questions` и `drafts` не удалены: репозиторий мигрирует их в новую книгу и продолжает поддерживать сценарий интервью.

В seed-данных аудио по-прежнему демонстрационное. Интервью записывает настоящий голос через `getUserMedia` + `MediaRecorder` (Opus/WebM, в Safari — MP4) с паузой и индикатором громкости. Записи и загруженные файлы (до 50 МБ) лежат в IndexedDB `family-stories-media` по `MediaAsset.id`; в snapshot остаётся только ссылка `idb:<id>`. Старые data URL переносятся в IndexedDB при загрузке. JSON-копия и HTML-книга встраивают медиа как base64 в момент экспорта.

## PWA

Подключён `vite-plugin-pwa`: генерируются manifest и service worker. Приложение можно установить из поддерживаемого браузера. При первом запуске проверьте production-сборку через:

```powershell
pnpm build
pnpm preview
```

## Известные ограничения

- семейное хранилище проверено только на поддельных сервисах Google, не на настоящем аккаунте; синхронизация не мгновенная, одновременные правки одной записи решаются в пользу той, что дошла последней; участники получают временный токен Диска, который открывает все книги хранилища;
- при обмене файлом книги удаления между устройствами не переносятся;
- автоматической расшифровки нет: текст ответа вводится вручную;
- записи хранятся только на этом устройстве; для переноса нужна резервная копия JSON;
- скачиваемая книга — HTML-файл, не PDF и не печатный заказ;
- фильм главы собирается в реальном времени и только пока вкладка открыта; голос браузера (синтез речи) записать в видео нельзя, поэтому озвучка — это ваш записанный голос;
- в демо-книге голосовые записи без настоящих файлов, поэтому в фильм они не попадают;
- данные привязаны к браузеру и могут быть очищены пользователем.
